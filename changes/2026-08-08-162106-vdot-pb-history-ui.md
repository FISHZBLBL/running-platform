# VDOT PB 历史与响应式布局优化

- 日期时间：2026-08-08 16:21:06（Asia/Shanghai）
- 涉及页面：跑力值
- 涉及文件：`shared/vdot.ts`、`src/App.tsx`、`src/styles.css`、`tests/predictions.test.ts`

## 改动内容

1. 为 3km、5km、10km 等真实标准距离 PB 增加历史成绩列表，展示成绩、配速、VDOT、心率、功率、步频、耗能评分和 PB 改善幅度。
2. 支持标记比赛记录，并区分当前 PB、历史 PB 和未刷新 PB 的比赛成绩。
3. PB 摘要卡片改为可展开按钮，同一时间只展开一个距离的历史详情，并补充 `aria-expanded` 状态。
4. 历史详情统一显示在全部 PB 卡片下方，避免打开中间卡片时其他卡片突然换行或错位。
5. 调整 PB 卡片的自适应排版：宽屏左右布局，平板宽度改为 VDOT 范围在上、PB 卡片在下，手机端使用紧凑单列卡片和两列详情指标。

## 修改原因

原有跑力值页面只显示当前 PB，无法查看成绩进步过程，也不能区分训练与比赛。新增历史详情后的初版在平板宽度下会把配速、日期和历史数量压成逐字竖排，并产生大片空白；展开中间卡片还会造成其余卡片重排。

## 解决的问题

- 可以按标准距离查看 PB 演进和比赛成绩，便于理解 VDOT 变化依据。
- 消除平板宽度下文字竖排、信息过度截断和摘要区异常留白。
- 消除展开详情时 PB 卡片位置跳动。
- 保持 iPhone 15 Pro（393×852 CSS 视口）下无横向溢出，卡片和详情均可读。
