# 2026-07-03 14:47:07 图表拖动条触控逻辑优化

## 改动内容
- 关闭 ECharts 底部 `dataZoom` 滑条的空白区域框选能力。
- 保留两个核心操作：
  - 拖动已有选区整体移动可视范围。
  - 拖动左右两侧手柄调整可视范围。
- 放大滑条高度和手柄尺寸，提升手机和平板上的可点按面积。
- 给滑条和手柄增加更清晰的颜色与边框。

## 为什么做这个改动
- 原来的滑条允许在空白处点击/拖动来新建选择范围，这在手机和平板上容易和“移动已有范围”“拖动边界手柄”发生交互冲突。
- 手柄较小，触控时容易拖错位置，导致想扩展日期范围时反而移动或缩小了范围。

## 解决的问题
- 避免误触空白区域生成新的选择范围。
- 降低移动端调整 X 轴范围时的误操作概率。
- 让用户更明确地通过两侧手柄控制范围，通过中间选区移动窗口。
