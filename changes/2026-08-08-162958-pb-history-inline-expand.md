# PB 历史详情就近展开

- 日期时间：2026-08-08 16:29:58（Asia/Shanghai）
- 涉及页面：跑力值
- 涉及文件：`src/App.tsx`

## 改动内容

将 PB 历史详情从整组卡片末尾移动到当前被点击的距离卡片后方。点击 3km 时，3km 历史立即显示在 3km 与 5km 卡片之间；点击其他距离时遵循相同规则。仍然保持一次只展开一个距离，并保留 `aria-expanded` 状态。

## 修改原因

整组末尾展开虽然能减少宽屏卡片重排，但在手机单列布局中会让 3km 的详情出现在 10km 卡片之后，用户需要越过其他距离才能看到刚刚请求的内容。

## 解决的问题

- 展开内容与触发它的 PB 卡片保持紧邻，信息归属更清楚。
- 手机端不再需要向下越过其他 PB 卡片查找详情。
- 保持 393×852 视口无横向溢出，并维持单一展开状态。

## 验证

- 浏览器确认元素顺序为：`3km 卡片 → 3km 详情 → 5km 卡片 → 10km 卡片`。
- iPhone 15 Pro CSS 视口（393×852）截图检查通过。
- 控制台无错误或警告。
