# 跑步趋势数据点连接优化

- 日期时间：2026-08-09 10:06:33（Asia/Shanghai）
- 修改范围：主页“跑步表现趋势”图
- 涉及文件：`src/App.tsx`

## 做了哪些改动

- 实际配速曲线平滑系数从 0.18 调整为 0.38。
- 3 次移动平均曲线平滑系数从 0.25 调整为 0.44。
- 平均心率曲线平滑系数从 0.18 调整为 0.38。
- 三条曲线统一增加 `smoothMonotone: "x"`，限制曲线沿时间轴单调平滑。

## 为什么这样修改

数据点较多且相邻变化较大时，原连接方式形成明显尖角，视觉上较生硬。适度平滑可以改善连续阅读体验；使用 X 轴单调约束能够减少普通贝塞尔曲线在数据点之间产生不真实峰值的风险。

## 解决的问题

- 配速和心率曲线的急转位置不再过于尖锐。
- 移动平均线呈现更连贯的整体趋势。
- 原始数据点位置保持不变，真实波动仍然可以辨认。

## 验证结果

- 本地页面实际渲染检查通过，曲线过渡自然且未出现明显过冲。
- TypeScript：`tsc -b` 通过。
