# 响应式界面与记录流程优化

- 日期时间：2026-08-22 06:07:40 +08:00
- 修改基线：`8dc4831`
- 修改范围：主页图表、移动端导航、记录录入页、个人资料菜单、桌面记录工作区

## 做了哪些改动

1. 手机端图表选中数据改为“日期标题 + 两列指标”，减少长文本挤压和信息显示不全。
2. 压缩手机端顶部区域，将导航固定为五个等宽入口；账户名称和退出操作收进个人资料菜单。
3. 将手机端导航、图表周/月切换、记录操作和跑鞋操作的可点击高度提高到至少 44px。
4. 手机端跑步记录表单默认保留日期、跑鞋、距离和用时，将跑步表现、环境、主观感受改为可展开区块。
5. 手机端保存按钮改为表单底部吸附，长表单滚动时仍可快速保存。
6. 切换主页面时自动回到页面顶部，避免从长页面切换后落在新页面中部。
7. 桌面记录页右侧增加记录概览，并让右侧栏随页面滚动保持可见，改善大屏空间利用率。

## 为什么修改

- 手机端原有页面顶部和记录标题区域占用过多纵向空间，常用字段需要滚动较远才能操作。
- 图表选中详情在窄屏中容易被压缩，阅读顺序不清晰。
- 一些按钮触控面积偏小，在 iPhone 上容易误触。
- 桌面记录页右侧只有体重表单，下面存在明显空白。

## 解决的问题

- 缩短手机端首次进入记录页后的操作路径。
- 提高图表详情在手机和平板上的完整性与可读性。
- 提高触控操作的稳定性。
- 改善桌面记录页左右栏的信息密度与平衡。

## 明确保留不变

- 按用户要求，没有修改 VDOT 表格的横向滚动提示。
- 按用户要求，没有修改跑鞋图片加载失败时的占位逻辑。
- 图表的数据选择、拖动范围和计算逻辑保持不变。

## 验证

- TypeScript 检查通过。
- 11 个测试文件、81 项自动化测试全部通过。
- Vite 生产构建通过；仅保留既有的 ECharts 大包体积提示，不影响部署。
- iPhone 15 Pro、平板和桌面三档视口的响应式检查通过，无页面横向溢出。
