# 科研图表视觉系统优化

- 日期时间：2026-08-09 09:25:18（Asia/Shanghai）
- 修改范围：主页五张 ECharts 图表
- 涉及文件：`src/App.tsx`、`src/styles.css`

## 做了哪些改动

1. 统一五张图表的颜色语义：蓝色表示主要观测值，绿色表示趋势，灰蓝色表示训练负荷，橙色表示心率，紫色表示体重-心率关系。
2. 统一坐标轴、网格线、文字颜色、点样式、线宽、柱形透明度和 Tooltip 样式，减少不同图表之间的视觉跳变。
3. 为每张图增加紧凑的统计摘要：样本量、最近配速、移动平均、Pearson 相关系数、最近跑量、最长单次、最近体重和区间变化。
4. 主趋势图保留实际配速、3 次移动平均、单次距离和平均心率，但降低距离柱和次要指标的视觉权重，突出真实配速。
5. 配速-心率图补充 Pearson 相关系数，并将拟合线改名为“线性趋势”；散点大小继续表示单次距离。
6. 体重趋势只展示原始记录，不增加移动平均；折线改为不平滑，避免暗示未观测到的中间变化。
7. 为 ECharts 开启可访问性描述，并为每张画布增加明确的中文 `aria-label`。
8. 修复 ECharts 画布的最小内容宽度撑开 CSS Grid 的问题，避免手机端整块图表超过屏幕、摘要被截断或页面产生横向滚动。
9. 保留原有拖动条、区间移动、周/月跑量切换和 Tooltip 交互。

## 为什么这样修改

原有图表数据完整，但颜色、坐标轴和视觉层级不统一，主图的多指标在小屏幕上会互相争夺注意力。此次参考高质量科研图表的原则，把每张图的核心问题、样本背景和关键统计量直接呈现，同时保留现有交互能力。

## 解决的问题

- 图表之间缺少统一视觉语言，阅读成本较高。
- 真实数据、趋势和辅助指标的主次不够明确。
- 相关性图只能看点位，缺少样本量和相关系数背景。
- 手机端 ECharts 画布会沿用桌面宽度并撑开页面。
- 图表的统计含义过度依赖点按 Tooltip 才能获取。
