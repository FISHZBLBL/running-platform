## 本次改动

### 1. 全站视觉系统

- 顶部改为完整的产品导航栏，增加统一品牌标记和用户信息区域。
- 首页核心指标改为统一的深色数据条，形成“指标概览 → 趋势分析”的阅读顺序。
- 统一页面颜色、边框、阴影、间距、按钮、表单、历史记录、VDOT 表和响应式规则。
- 保留五张趋势图各自原有的横轴拖动条、两侧手柄和可视范围逻辑。

### 2. 独立预测建议页面

- 导航新增“预测建议”。
- 将目标模式、目标距离、目标时间/日期、VDOT 预测、风险提示和训练建议从主页迁移到独立页面。
- 主页只保留核心指标和趋势图，避免后续新增预测模型时继续挤压主页。
- 保留“输入完成后点击更新预测”的应用逻辑，未恢复逐字符刷新。

### 3. 鞋库采用方案 3

- 改为性能卡片布局：桌面三列、平板两列、手机两列，极窄屏单列。
- 跑鞋照片容器固定为 1:1，适配之后上传的正方形照片。
- 每张卡片展示真实计算的累计跑量、关联跑步次数和最近使用日期。
- 编辑与删除放在卡片底部左右两端，减少误触并贴近所选预览方案。
- 使用量细轨道只表示已存在里程记录，不显示虚构的寿命百分比。
- 新增 `src/shoe-library.css`，在全局样式之后加载，避免旧鞋库规则再次覆盖最终布局。

### 4. 手机数字键盘

- 距离和气温使用小数键盘。
- 心率、步频、功率、湿度、AQI 以及分段整数数据使用纯数字键盘。
- 总用时、平均配速和分段配速使用数字键盘，并在离开输入框时自动补冒号：
  - `4530` → `45:30`
  - `11408` → `1:14:08`
  - `520` → `5:20`

## 解决的问题

- 页面由大量相似白色卡片堆叠变为层级更清楚的运动数据工作台。
- 预测和建议不再占用主页右侧空间，为后续接入更复杂预测方案留出独立区域。
- 鞋库照片区域不再因宽比例容器产生大量空白，手机可以稳定双列管理。
- 手机录入跑步数据时不再频繁切换完整键盘和数字键盘。
