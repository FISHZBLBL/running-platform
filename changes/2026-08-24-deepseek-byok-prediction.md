# DeepSeek 用户级智能预测

- 在个人资料中增加 DeepSeek API Key 验证、加密保存、替换与删除。
- 使用现有 `JWT_SECRET` 通过 HKDF 派生 AES-256-GCM 密钥，Key 按账户独立存储且永不回显。
- 为兼容 Netlify Free 每项目 2 条代码级限流规则的上限，AI 设置与预测接口依靠登录校验、数据指纹缓存和账户级并发锁，不额外占用规则；认证与上传继续保留两条边缘限流。
- 数据变化时不立即调用模型；进入预测页后基于数据指纹懒生成并缓存 Flash 分析。
- AI 数值调整必须落在现有预测引擎的动态区间内，超界时保留算法基线。
- 增加用户主动触发的 Pro 深度分析，且不生成第三套预测数字。
- 最新分析保存完整内容，旧分析仅保留精简回测快照。
- 本地 Netlify 开发环境使用 `.netlify/local-data` 持久化，纯 Vite 预览明确禁用密钥保存。
