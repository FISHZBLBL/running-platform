# iPhone Web App 图标与主屏幕启动配置

- 日期：2026-08-30
- 修改范围：网页入口与 Web App 清单

## 做了哪些改动

1. 复用已确认的“路线 + 心率”图标作为 Apple Touch Icon，没有修改图案、配色或造型。
2. 新增 `manifest.webmanifest`，配置应用名称、简称、主题色、启动范围和独立显示模式。
3. 增加 iOS Web App 声明，使网站从 iPhone 主屏幕启动时以独立窗口显示。
4. 增加主屏幕名称“跑步平台”和与网站一致的蓝色主题色。

## 为什么做这个改动

- 之前只有浏览器标签页 favicon，没有声明 iPhone 主屏幕图标和 Web App 启动方式。
- 用户主要通过 iPhone 将网站作为 App 使用，需要稳定的图标、名称和独立窗口体验。

## 解决的问题

- iPhone“添加到主屏幕”时会使用网站自己的图标，而不是默认网页缩略图。
- 从主屏幕启动后减少 Safari 浏览器界面干扰，体验更接近独立 App。

## 使用说明

- 已经添加过的旧主屏幕快捷方式不会自动刷新图标，需要先删除旧快捷方式，再从 Safari 重新选择“添加到主屏幕”。

## 验证

- `100/100` 项自动化测试通过。
- TypeScript 检查和 Vite 生产构建通过。
- 构建产物中已包含 `manifest.webmanifest`。
- 仍有既有的 ECharts 大包体积提示，不影响 Web App 图标和主屏幕启动。
