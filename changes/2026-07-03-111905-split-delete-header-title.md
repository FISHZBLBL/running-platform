# 2026-07-03 11:19:05 分段删除与站点标题调整

## 改动内容
- 跑步记录的分段表格每一行新增“删除”按钮。
- 手动新增分段或截图识别出多余分段后，可以删除任意一段，不再只能覆盖或重新识别。
- 分段表格列宽调整，手机端继续保持横向滚动。
- 网站顶部主标题从“跑步数据分析台”改为 `RUNNING PLATFORM`。

## 为什么做这个改动
- 之前点击“+ 分段”过多，或者 OCR 识别出了多余分段时，用户无法直接删除某一段，尤其尾段会影响后续分析。
- 页面抬头希望更简洁，只保留平台名称。

## 解决的问题
- 分段数据录入和校对更可控。
- 多余分段可以在保存前直接清理，减少错误数据进入记录。
- 顶部视觉信息更集中。
