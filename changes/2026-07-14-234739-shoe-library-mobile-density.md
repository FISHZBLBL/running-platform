# 鞋库手机布局与信息密度调整

- 时间：2026-07-14 23:47:39 +08:00
- 范围：鞋库页面
- 部署：未部署，仅本地预览

## 修改内容

1. 跑鞋照片容器固定为 1:1 正方形，图片使用正方形区域完整铺放。
2. 手机端鞋库保持两列卡片，只有屏幕宽度小于 340px 时才退回单列。
3. 将“鞋库”和跑鞋数量放在同一行，数量靠右并与标题底边对齐。
4. 减少卡片标题、数据指标、进度线和操作区之间的垂直留白。
5. 编辑和删除按钮保持分开排列，并保留适合触控的最小高度。

## 修改原因

后续跑鞋照片主要使用 1:1 图片，原来的横向图片容器会产生较多空白；同时手机端标题区和卡片正文偏松散，降低了两列布局的空间利用率。

## 解决的问题

- 手机端可以同时查看两双跑鞋，减少滚动距离。
- 正方形照片不会因横向容器产生大面积留白。
- 鞋库标题与数量关系更清晰，新增表单更靠近标题。
- 卡片信息更紧凑，但编辑和删除操作仍然容易点击。

## 验证

- 390 x 844 手机视口：两列宽度均为 175px。
- 首张照片显示区域约为 173.4 x 173.4px。
- 标题和数量底边差为 0px。
- 页面无横向溢出，浏览器控制台无错误或警告。
