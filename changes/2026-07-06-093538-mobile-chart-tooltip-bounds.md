# 2026-07-06 09:35:38 - 修复移动端图表 Tooltip 显示不全

## 改动内容
- 新增统一的 ECharts tooltip 配置函数，为所有图表 tooltip 增加边界约束。
- tooltip 会根据数据点位置自动调整弹出方向，避免在手机窄屏时向左或向下溢出。
- tooltip 内容增加最大宽度、自动换行和阴影样式，提升手机和平板端可读性。
- `体重与跑步表现`、`配速与心率` 两个散点图的 tooltip 改为多行展示：
  - 体重、配速、心率、距离、日期分别独立成行。
  - 避免原来一整行信息在窄屏中被裁切。
- 统一应用到趋势图、体重趋势图、周/月跑量图，减少同类问题再次出现。

## 修改原因
- 在手机端点击 `体重与跑步表现` 和 `配速与心率` 图表时，tooltip 会贴近图表左侧弹出，导致内容被裁掉。
- 两个散点图的数据字段较多，原本使用一行展示，在移动端宽度不足时容易显示不完整。
- 平板端也需要检查同类响应式问题，避免宽度变化时图表或 tooltip 超出容器。

## 解决的问题
- 手机端 tooltip 不再因为靠近左侧或底部而显示不全。
- 散点图数据改为多行，更容易阅读。
- 平板端检查结果显示图表宽度正常，没有横向溢出。

## 验证
- `npm run build` 通过。
- `npm run test` 通过，14 个测试全部通过。
- 手机视口 `390 x 844` 下图表可正常加载。
- 平板视口 `820 x 1180` 下五张图表宽度正常，无横向溢出。

## 注意事项
- 本次只修改图表 tooltip 的显示方式，没有改变图表数据、预测算法或存储结构。
