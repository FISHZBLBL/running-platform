# 跑步距离柱状图配色调整

- 日期时间：2026-08-09 10:01:40（Asia/Shanghai）
- 修改范围：主页“跑步表现趋势”图
- 涉及文件：`src/App.tsx`

## 做了哪些改动

- 将“单次距离”柱状图从灰蓝色 `#8295a8` 改为珊瑚色 `#e76f51`。
- 将柱形透明度从 0.34 调整为 0.46，使颜色更鲜明但仍处于折线之后。

## 为什么这样修改

原灰蓝色柱状图视觉感受偏沉，与页面浅色背景结合后缺少活力。珊瑚色可以和蓝色配速、绿色移动平均、橙色心率形成更清楚的色彩区分，同时保持科研图表需要的克制感。

## 解决的问题

- 柱状图不再显得灰暗、沉闷。
- 单次距离更容易从图例和图表中辨认。
- 保留透明度和较低层级，不遮挡主要配速折线。

## 验证结果

- 本地页面实际渲染检查通过，图例和柱形颜色一致。
- TypeScript：`tsc -b` 通过。
- 生产构建：Vite 构建成功；仅保留既有的 ECharts 大包体积提示。
- 本次未部署。
