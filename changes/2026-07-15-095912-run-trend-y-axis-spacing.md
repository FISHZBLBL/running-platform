# 跑步表现趋势图右侧 Y 轴间距调整

- 时间：2026-07-15 09:59:12 +08:00
- 范围：首页跑步表现趋势图
- 部署：未部署，仅本地预览

## 修改内容

1. 将心率 Y 轴相对距离 Y 轴的偏移由 52px 增加到 82px。
2. 增加距离轴和心率轴名称与轴线之间的间距。
3. 图表右侧预留空间由 126px 增加到 166px。
4. 为两个右侧纵轴的刻度标签设置统一的 10px 间距。

## 修改原因

距离和心率两个纵轴都放在图表右侧，原有偏移不足，导致“距离 km”和“心率 bpm”视觉上过于接近，不容易快速判断刻度归属。

## 解决的问题

- 两个右侧纵轴名称不再拥挤。
- 距离与心率刻度的归属更加清晰。
- 手机端继续使用简化标签，不会因为新增间距压缩绘图区。

## 验证

- 886 x 698 平板视口检查：两个右侧轴名称和刻度均正常分离。
- 390 x 844 手机视口检查：页面无横向溢出，图表宽度约 328.4px。
- 浏览器控制台无应用错误或警告。
