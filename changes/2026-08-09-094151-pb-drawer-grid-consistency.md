# PB 历史成绩展开排版一致性修复

- 日期时间：2026-08-09 09:41:51（Asia/Shanghai）
- 修改范围：跑力值页面 PB 卡片网格
- 涉及文件：`src/styles.css`

## 问题原因

PB 历史明细横跨整个卡片网格，并紧跟在被点击的卡片后面。点击第一列的 3km 卡片时，明细无法放进右侧剩余半列，因此会先换到下一整行，后续的 5km 卡片再被排到明细之后；点击第二列的 5km 卡片时，该行已经排满，所以不会出现这个空位。

## 做了哪些改动

- 为 PB 卡片网格增加 `grid-auto-flow: row dense`。
- 允许后续尚未展开的 PB 卡片自动回填当前行的空列。
- 历史明细继续保持横跨整行，并紧接当前卡片所在行之后展示。
- 单列手机布局不受影响，仍然是卡片后立即展示对应历史明细。

## 解决的问题

- 展开 3km 和展开 5km 时不再出现不同的桌面排版。
- 消除第一列卡片展开时的右侧大片空白。
- 3km 与 5km 卡片会保持同一行，历史明细统一在下一整行展开。

## 验证结果

- 浏览器实测：3km 和 5km 展开后的明细顶部位置一致，均横跨两列。
- 单元测试：10 个测试文件、76 项测试全部通过。
- TypeScript：`tsc -b` 通过。
- 生产构建：Vite 构建成功；仅保留既有的 ECharts 大包体积提示。
- 本次未部署。
